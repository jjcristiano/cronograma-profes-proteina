# 🏋️ Proteína Gym — Sistema Web de Gestión de Horarios y Liquidaciones
## 1. Proteína Gym · 2. Proteína Box · 3. Boxeo

Sistema web administrativo centralizado para la gestión de cronogramas mensuales (`Noviembre 2026` a `Diciembre 2027`), administración de profesores, registro de reemplazos y liquidación automática de las tres unidades:
- **1. Proteína Gym**
- **2. Proteína Box**
- **3. Boxeo**

---

## 📂 Estructura de Archivos del Repositorio

| Archivo | Descripción |
| :--- | :--- |
| `index.html` / `webapp/index.html` | **Aplicación Web Administrativa** lista para abrir en cualquier navegador (computadora o celular). Guarda los cambios automáticamente en el navegador (`localStorage`). |
| `LOGO_GYM_PROTEINA.PNG` | Logo oficial de **Proteína Gym**. |
| `INSTRUCTIVO_Y_MANUAL_DE_USO.md` | Guía simple paso a paso para usar la aplicación web. |
| `HISTORIAL_CONVERSACION_Y_ESPECIFICACION.md` | Historial de decisiones de diseño y reglas del sistema. |

---

## 🚀 Cómo Usar el Sistema

1. Abre el archivo `index.html` (o `webapp/index.html`) con doble clic en cualquier navegador web (Google Chrome, Microsoft Edge, Safari).
2. Todos los cambios que realices (asignar turnos, cambiar nombres, agregar profesores, cambiar el valor de la hora o cargar feriados) quedan guardados automáticamente en el navegador.
